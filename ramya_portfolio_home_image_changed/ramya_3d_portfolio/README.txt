RAMYA — CINEMATIC 3D-INSPIRED PORTFOLIO

HOW TO RUN
1. Extract ramya_3d_portfolio.zip.
2. Open the ramya_3d_portfolio folder.
3. Double-click index.html to open it in Chrome, Edge, or Firefox.
4. For a local server, open a terminal in the folder and run:
   python -m http.server 8000
   Then visit http://localhost:8000

CUSTOMIZE
- Edit index.html to change the name, bio, projects, education, and email.
- Edit style.css to change colors, spacing, or typography.
- Replace assets/ramya-villa-hero.jpg with your preferred house-and-person image.
- Update assets/ramya-resume.txt with your real resume details.

NOTES
- This is a responsive, 3D-inspired portfolio with a cinematic house scene, parallax movement, hover effects, navigation, project cards, and contact links.
- The supplied hero art is a generated concept image, not an actual photograph of a specific house or a real person's portrait.
- The email ramya@example.com is a placeholder. Replace it before publishing.
- Google Fonts requires internet access; the website remains readable if fonts cannot load.
